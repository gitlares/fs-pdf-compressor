A private PDF compressor for Mac.

FS PDF Compressor makes PDFs smaller entirely on your Mac. Drop in a file, a batch, or a folder and choose Preserve, Balanced, or Maximum. There are no uploads, accounts, analytics, or subscriptions.

Install on Mac

Three simple steps.

The public DMG is signed with Developer ID and notarized by Apple, so it works with Gatekeeper enabled.

  1. 1Download the Apple Silicon DMG
  2. 2Drag FS PDF Compressor to Applications
  3. 3Open it and drop in a PDF

Mac questions

Before you download.

Does it support Intel Macs?
No. The published Mac build currently requires Apple Silicon and macOS 14 or later.
Are PDFs uploaded?
No. Ghostscript runs locally inside the application bundle.
Can I keep the original?
Yes. Enable Keep original to create a separate compressed copy.
How do I verify the app?
macOS validates the Developer ID signature and Apple notarization. Release details are published on GitHub.
