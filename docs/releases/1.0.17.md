# 1.0.17 — Color fidelity and Smart scans

FS PDF Compressor checks embedded ICC color profiles, page dimensions, and selectable
text before saving a compressed PDF. When the app can identify an empty profile
unambiguously, it retries compression at the original image resolution and
restores the profile from the source PDF. If validation fails, it keeps the
original.

**Smart scans** adds adaptive compression for black-and-white documents. Thanks
to [@MicheleFerr](https://github.com/MicheleFerr) for contributing this feature
in [PR #18](https://github.com/gitlares/fs-pdf-compressor/pull/18).

The Windows installer adds WinSparkle for signed update downloads and
user-approved installation. Existing Windows users can install this version
manually to enable future updates. Portable updates are manual.
