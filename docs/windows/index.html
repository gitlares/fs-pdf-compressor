A private PDF compressor for Windows.

Compress PDFs without sending them to a website. FS PDF Compressor runs locally, supports files, batches, and folders, and adds an optional action to Windows Explorer.

Windows version at a glance

Privacy
No uploads, accounts, analytics, or telemetry.
Installation
Per-user installer; administrator access is not required.
Workflow
Drag and drop, Explorer action, or optional Drop Zone.
Verification
SHA-256 checksums are published with each release.

Current limitation: the Windows installer is not yet code-signed, so Windows may show an unknown publisher warning. Verify the published checksum before installing.

01

Works from Explorer

Select PDFs and choose Compress with FS PDF Compressor. Windows 11 may place the action under Show more options.

02

Built-in engine

Ghostscript and the required runtime are bundled. There is no separate dependency to configure.

03

Originals are recoverable

When replacing a file, the app first tries to move the original to the Recycle Bin. Keep original creates a separate copy and remembers your choice.

Install on Windows

Install per user.

Download the installer and its matching checksum from the same GitHub release. A portable ZIP is also available.

  1. 1Download the x64 installer and SHA-256 file
  2. 2Verify the checksum and run the installer
  3. 3Open the app or use the Explorer action

Windows questions

Before you download.

Why does Windows show a warning?
The current installer is unsigned. Its checksum is published so you can verify the exact downloaded file.
Does it require administrator access?
No. The installer is designed for the current Windows user.
Are PDFs uploaded?
No. Compression runs locally on your computer.
Does it update automatically?
Not currently. Windows updates are installed manually from the official GitHub release.
