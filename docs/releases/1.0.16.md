# 1.0.16 — Ghostscript compatibility correction

FS PDF Compressor 1.0.16 restores Ghostscript 10.07.1 across macOS, Windows,
AppImage, and Snap. A regression in Ghostscript 10.08.0 could omit a text-based
clipping operation in some Photoshop-generated PDFs, allowing a mostly white
image layer to cover the page after compression even though Ghostscript
reported success.

The reported PDF was reproduced locally and then compressed and rendered with
all three quality profiles using Ghostscript 10.07.1. Its visible content is
preserved. No interface, profile, privacy, update, or file replacement behavior
changes in this release.

Version 1.0.16 is available as a signed and Apple-notarized macOS DMG, an
unsigned Windows installer and portable ZIP with SHA-256 checksums, a Linux
AppImage with update metadata and checksum, and a Snap Store release.

[GitHub release](https://github.com/gitlares/fs-pdf-compressor/releases/tag/v1.0.16).
