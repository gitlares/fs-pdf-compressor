The essentials

What you need to know.

A small app should not require a long explanation. These are the facts that matter before downloading FS PDF Compressor.

What is FS PDF Compressor?
FS PDF Compressor is a free desktop app that compresses PDF files locally with Ghostscript. The name means Fast & Simple.
Are PDF files uploaded anywhere?
No. PDF contents never leave your computer. The app has no account, cloud processing, analytics, telemetry, or subscription.
Which computers are supported?
FS PDF Compressor supports macOS 14 or later on Apple Silicon and x86_64 Linux through a self-contained AppImage.
Can I control compression quality?
Yes. Balanced is the default profile, with Preserve and Maximum available when quality or file size matters more.
What is Drop Zone?
Drop Zone is an optional desktop target that compresses PDFs without reopening the main window. On macOS, enable or disable it from FS PDF Compressor → Show Drop Zone; it appears in every Space. On Linux, use Application → Show Drop Zone. X11 can keep it at desktop level, while Wayland compositors may present it as a normal floating utility because they control window placement and stacking.
What happens to the original PDF?
The original is replaced only when the compressed result is smaller. Keep original mode creates a separate compressed copy instead.
Is the app safe to install?
The macOS DMG is Developer ID signed and notarized by Apple. The Linux AppImage is published with a SHA-256 checksum.
