Install on Linux

Snap or AppImage.

Snap is the simplest managed installation. The AppImage is portable and is published with a matching SHA-256 checksum.

  1. 1Choose Snap Store or download the AppImage
  2. 2For AppImage, verify its SHA-256 checksum
  3. 3Open it and drop in a PDF or folder

Linux questions

Before you install.

Which architecture is supported?
The published Linux packages currently target x86_64 systems.
Do I need Ghostscript?
No. It is bundled with the Snap and AppImage distributions.
Are PDFs uploaded?
No. Compression runs locally without a cloud service.
Which package should I choose?
Choose Snap for managed updates. Choose AppImage when you prefer a portable file outside the store.
