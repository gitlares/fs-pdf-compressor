# 1.0.14 — Safer replacement and aligned desktop builds

This maintenance release aligns macOS, Windows, AppImage, and Snap on the same
compression behavior and version. It keeps the existing interface, three
quality profiles, and local-only workflow.

## What changed and why

- **Best-effort recovery when replacing:** with Keep original off, the app
  first tries to send the old PDF to the system trash. If trash is unavailable,
  it still replaces the original with the smaller validated output. In that
  case the old file may not be recoverable. Keep original still creates a
  separate compressed copy; no third mode or extra backup copy is introduced.
- **Safer file handling:** unique temporary files, document locks, basic PDF
  output validation, and changed-input detection reduce conflicting writes
  and avoid replacing a PDF with empty or truncated output.
- **Responsive batches:** folder discovery runs in the background. Normal
  quitting and AppImage update restarts wait for active work to finish.
- **Platform alignment:** each build embeds the same version. Windows points
  to manual release downloads; Snap explains Store-managed updates. macOS
  retains Sparkle's signed updates.
- **Snap runtime fix:** bundled Ghostscript resources, fonts, and color
  profiles are available inside confinement; missing Wayland runtime libraries
  are included.
- **Bounded diagnostics:** rotated logs prevent unlimited log growth.

## Downloads

- macOS 14+ on Apple Silicon: Developer ID signed, notarized DMG; ZIP for
  Sparkle updates.
- Windows 11 x64 (including x64 emulation on Windows ARM): per-user setup
  executable or portable ZIP. The Windows package is **unsigned** and may
  trigger SmartScreen. Run the setup executable, or keep the entire portable
  folder together with its `_internal` directory. Python is included.
- Linux x86_64: AppImage with matching SHA-256 and zsync metadata; Snap Store
  distribution follows candidate verification.

Compression and recovery were tested with generated PDFs on macOS, Windows,
and Linux. The final macOS and Windows interfaces were also confirmed by the
maintainer. Snap's unavailable-trash fallback passed on Magnolia; successful
host-trash recovery there was not established. Basic PDF validation does not
guarantee visual fidelity for every document: review important results and use
Keep original when an unchanged original must be retained.
