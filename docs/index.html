The essentials

What you need to know.

A small app should not require a long explanation. These are the facts that matter before downloading FS PDF Compressor.

What is FS PDF Compressor?
FS PDF Compressor is a free, open-source desktop app that compresses PDF files locally with Ghostscript. The name means Fast & Simple.
Can I compress PDFs without uploading them?
Yes. PDF contents never leave your computer. The app has no account, cloud processing, analytics, telemetry, or subscription.
Which computers are supported?
FS PDF Compressor supports macOS 14 or later on Apple Silicon, Windows 11 x64, and x86_64 Linux through Snap or a self-contained AppImage.
Can I control compression quality?
Yes. Balanced is the default profile, with Preserve and Maximum available when quality or file size matters more.
What is Drop Zone?
Drop Zone is an optional desktop target that compresses PDFs without reopening the main window. It is shown on first launch on Windows; closing the main window leaves it available. On macOS, enable or disable it from FS PDF Compressor → Show Drop Zone. On Linux, use Application → Show Drop Zone; Wayland compositors may present it as a normal floating utility because they control window placement and stacking.
What happens to the original PDF?
The original is replaced only when the compressed result is smaller. On Windows, the replaced original is moved to the Recycle Bin; Keep original mode creates a separate compressed copy instead.
Is the app safe to install?
The macOS DMG is Developer ID signed and notarized by Apple. Linux and Windows downloads are published with SHA-256 checksums. The Windows installer is currently unsigned, so verify its checksum before installing.

First launch

Ready to open.

The macOS app is Developer ID signed and notarized by Apple. On Linux, install from Snap Store or use the self-contained AppImage. On Windows, verify the published checksum for the unsigned per-user installer.

macOS

  1. 1 Download the DMG
  2. 2 Drag the app to Applications
  3. 3 Open the app

Linux

  1. 1 Install from Snap Store, or download the AppImage
  2. 2 Snap updates automatically; AppImage stays portable
  3. 3 Open it—nothing else to install

Windows

  1. 1 Download the x64 installer and matching checksum
  2. 2 Verify the checksum, then run the per-user installer
  3. 3 Use Explorer's Compress action or the Drop Zone
